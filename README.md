# THHG Cricket Club website

Standalone homepage prototype for Thorpe Hesley & High Green Cricket Club.

## Preview

Open `index.html` in a browser, or host the static files on GitHub Pages.

## Included

- Responsive navigation and hero
- Our Club, Teams, Fixtures, Honours, Sponsors and Contact sections
- Links to official Play-Cricket website
- Honours-board design placeholder

## Next steps

Replace placeholder content with approved club text, photography, crest, sponsor details, and integrate the Play-Cricket API through a secure build step. **Never place the Play-Cricket API token in browser-side JavaScript.**
